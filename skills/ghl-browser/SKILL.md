# ghl-browser

Read [computer execution](references/guide.md) before using an Orgo session. Discover actual installed computer tools rather than inventing tool names. Before navigating, get the page's direct URL, menu path and help articles from `ghl hub open PAGE` (MCP `ghl_dashboard`; no page lists them) and open that URL instead of hunting through menus. URLs are known patterns, not guarantees: confirm the heading and selected sub-account, and fall back to the menu path if redirected. Confirm the computer, browser account, and sub-account, then follow the task-specific specialist's guide. Screenshots and current help articles determine current UI labels. An inaccessible API endpoint is not permission to extract session tokens or switch accounts.
