# ghl-workflows

Read [workflow procedure](references/guide.md). Locate `ghl` with [installation](references/installation.md). The public workflow endpoint lists workflows; contact enrollment lives under contacts. Constructing a workflow graph uses the dashboard. The inherited experimental Firebase builder is not the normal supported route. Preserve trigger filters, re-entry behavior, timezones, exit conditions, and branch semantics when implementing a workflow.
